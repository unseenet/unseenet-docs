# How do I …

This is the user guide: one page per thing you want to do, for both
clients. Each page has a tab for the **graphical** client and one for the
**terminal** client; pick the one you use, and the other pages follow your choice.

Unseenet looks like programs you know, but a few ideas behind it are new
if you come from Discord, Facebook or Matrix - there is no account, no
server that owns you, and a new identity needs a little while before it
can post freely. The pages explain those ideas in a sentence or two where
they matter, and link to [How it works](../guide/index.md) for the why.

| use another node, or several | [Nodes](nodes.md) |
